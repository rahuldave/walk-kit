# The class material for @project@

The notes, the slides and the recipes for a class that walks through the steps of @project@ with
[timewalk](https://rahuldave.com/timewalk/). This repository is private. Students get the public walk repository,
`@project@-walk`, which `just walk-init` makes and `just walk-update` keeps up to date.

The class has one walk, `notes.md` and `slides/`, or several, listed in `toc.toml`. On a new machine, run `just setup` first. It clones the project and `@project@-walk` beside this folder. Run
`just` to see the recipes. `AGENTS.md` says how the parts fit, for people and for coding agents.
